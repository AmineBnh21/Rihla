# Logos des compagnies

Dépose ici le logo officiel de chaque compagnie, nommé par son code IATA :
`AH.svg` (Air Algérie), `TO.svg` (Transavia), `5O.svg` (ASL Airlines France),
`AF.svg` (Air France), `V7.svg` (Volotea). Le `.png` marche aussi.

- Prends-les dans le kit presse officiel de chaque compagnie (ou via le service d'images
  Travelpayouts si ton compte l'autorise), et respecte leurs règles d'usage.
- Ne modifie pas les logos (couleurs, proportions).
- Note la source de chaque logo dans `../CREDITS.md`.

Tant qu'un fichier manque, le bandeau affiche le nom de la compagnie en texte.
